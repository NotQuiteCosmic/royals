# Probe weight sets

Not champions and not candidates: sane variants of champ-001 used only to give the book-
ranking sweeps distinct match-ups. An opening's decisiveness is measured across several
different pairs of evaluators at one depth (see tuning/RESULTS.md, "A balanced book"), and
these are the other pairs. Each differs from champ-001 in one or two weights by an amount
that plays a different game without playing a bad one.
